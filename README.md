# Tami Omole — Engineering portfolio

An aerospace field journal with editorial typography, project imagery, and an interactive orbital index. Built with HTML, CSS, and vanilla JavaScript.

## Preview

Run `python -m http.server 8080` in this folder and open http://localhost:8080.
No build step or dependencies are required.

## GitHub Pages

Push this directory to a GitHub repository. In Settings → Pages, choose Deploy from a branch, then main and / (root).

## Editing

- index.html: page content, experience, and project overview.
- app.js: project descriptions, image galleries, and orbital selector.
- styles.css: typography, colors, and responsive layout.
- assets/: original project media and downloadable documents.

Project screenshots and documents belong to Tami Omole and their respective project organizations. No third-party portfolio code or imagery was copied. The design uses an original field-journal layout and project index, built around Tami’s engineering work.

Rocketry analysis is in progress. Displayed results are preliminary and must not be treated as flight qualification.

## Current airframe update
The airframe is fiberglass. Current galleries show six- and eight-ply axial compression and pure-bending studies. Earlier carbon-fiber presentation material is historical and is not linked as current project evidence.
